# 판정 기준 — 회로 모델 게이트 + 장소 C 4차 펌웨어 (2026-09-04, 결과 전에 적음)

`run_circuit_gate_probe` 가 재는 것과, 무엇이 나오면 무엇이라고 읽을지.

```
[1] 게이트 4   가이드 §4.2 파라미터로 sp_curves 를 평균 손실 < 0.01 로 재현하면 "출발점으로 쓸 수 있다".
              0.01~0.05 면 "모양은 맞고 고차가 틀리다" (§3.3 의 누락 요소).  > 0.05 면 토폴로지 재검토.
[3] 지연 검정  5C/4_fixed 비가 |비| 1±0.1, ∠비 h 선형 잔차 < 2° 면 **계측** (채널 지연 또는 교정 상태 — 펌웨어의
              위상 교정이 −h×delay 회전이라 둘은 같은 모양이다). 잔차가 크거나 |비| 가 차수에 따라 변하면
              파형(장소) 차이가 섞인 것. 저항 부하의 기본파가 0 이면 채널 지연은 아니다 (사후 추가: 드라이기 4C 가 그렇게 갈랐다).
[4] 게이트 5   시뮬 T_sim 이 실측 T_C(옛 펌웨어 = 지연 없는 쪽) 와 h3~h9 에서 부호가 같고 크기가 0.5~2배면
              "전압축 기작 확인". 부호가 반대면 vhdeg 부호/기저 관례 문제. 전 차수를 넣었을 때
              h3 만 넣은 것보다 나빠지면 고차 vh 위상(또는 시뮬의 고차 응답) 이 틀린 것.
[5] 짝수차     ∠vh2 원형표준편차 < 5° 이고 ∠I2 > 30° 면 vh2 는 전압 채널 인공물 후보 — 저항 부하로 확정.
```

## 추가 (2026-09-04 저녁, 결과 전) — 포트 전압계와 장소 C 재피팅 (`run_site_voltage_probe`)

```
[1] 포트 전압계   같은 장소·같은 날의 두 저항(포트·핫플)이 주는 ∠V_h 가 h3~h9 에서 15° 안이면 방법이 선다.
                 그보다 크면 HIGH 레인지의 저항 고조파 전류(0.3~1%)가 분해능·이음매 바닥이라 못 쓴다 — 그러면
                 옛 녹화로 장소 A·B 파형을 복원하지 않는다 (그 파형으로 맞춘 파라미터는 잡음을 박는다).
[3] 장소 C 재피팅 실측 파형(vhdeg)으로 minipc_4C / 5C 의 s(p) 를 맞춘다. 손실 < 0.01 이 게이트 4 (장소 C 판).
                 파라미터가 §4.3 범위 안이어야 한다 (C_dc 0.3~2µF/W, R 1~3Ω, L 20~500µH(초크면 더), Cx 0.1~1µF, rd 0.3~3Ω).
[4] 전이         C 에서 맞춘 파라미터로 이상 정현파 장소 A 곡선(sp_curves)을 낼 때 손실 < 0.02 면 "장소를 넘어 서는
                 파라미터". 예측 T_C 는 h3~h9 위상 15° 안 + |T| 의 방향(감소)이 맞아야 크기축 통과.
                 장소 B 는 V_B 가 불확실하면 참고로만 적는다 (판정하지 않는다).
```

## 추가 (2026-09-04 밤, 결과 전) — §3.3 누락 요소 (`run_circuit_element_probe`)

과녁: 장소 C 재피팅(12.184.9)의 잔차 — 미니PC 22~30W 와 충전기 38W 에서 시뮬 |s13| 이 0.05 로 꺼지는데
실측은 0.11~0.23 이고 위상이 뒤집힌다. 지표는 `res13_15` = 그 중부하 점들의 |Δs13|+|Δs15| 평균.
```
E0 입력 민감도   V 를 h1~h7 로 제한하고 재피팅. 손실·res13_15 가 전 홀수차 판과 20% 안이면 잔차는 입력(고차 vh 위상)이
                아니라 **모델**이다. 크게 줄면 고차 vh 위상이 범인 — 그러면 E1~ 는 h1~h7 입력으로 돌린다.
E1 지수 다이오드  v_d = Vf + rd·i + nVt·ln(1 + i/10mA). 무릎이 부드러워진다. nVt 0.01~0.3 V 가 물리 범위.
E2 초크 병렬 감쇠  L ∥ Rp (Rp 1~200 Ω). 고차에서 임피던스가 Rp 로 포화해 고차 전류가 더 통한다.
E3 직류 부하 지수  i_load = (P/V0)(V0/v_c)^α. α=1 정전력(지금), 0 정전류, −1 저항. DC-DC 루프 대역 대용. 범위 −1~1.
채택 기준 (요소 하나당): 두 기기 모두 손실 30% 이상 감소 **그리고** res13_15 절반 이하 **그리고** 기존 5개가 §4.3 안에
남고 새 파라미터가 물리 범위 안 **그리고** 충전기 T_C(2배 과다)·T_B(절반) 가 실측 쪽으로 움직인다.
하나만 만족하면 "부분", 손실만 줄고 res 가 그대로면 "잔차의 자리가 아니다". 둘 이상 채택되면 합쳐서 다시 맞춘다.
```
