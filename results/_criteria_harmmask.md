# 판정 기준 — `L_harm` 의 오차 바닥을 끊는다 (12.171.4 의 A·B)

**결과보다 먼저 적는다 (규칙 22). 시드 3개 (규칙 50).**

## 왜
12.171 이 잰 것: 미니PC 12W 의 배분 판별 신호는 계단 차분에서 **8~18% 마진**으로
존재하는데, 손실이 보는 절대 창에서는 10W 를 정답 쪽으로 옮기면 오차가
**+2.04% 나빠진다.** 오차 바닥 1.767 이 신호의 50배라 부호까지 뒤집힌다.
그 바닥의 구성:
```
짝수차 7개    37.8%    예측 3.3mA / 관측 7~9mA   미니PC 10W 의 몫 0.16~0.36mA
h11~h15 5개   56.0%    예측이 관측의 1/4~2/3 (h15 21.6 vs 92.4 mA)
```
둘 다 **기기 배분과 무관**하다. 끊으면 신호 대 바닥 비가 올라간다.

## 자 (전부 `cnn_sp.pt` 계보, 2단계만, 시드 0/1/2)
```
sp    대조   마스크 그대로 (차수 15개)          (있음)
hoA   처방A  --harm-odd-only          -> 8개
hoB   처방B  --harm-max-order 9       -> 9개
hoAB  처방AB 둘 다                    -> 5개 (h1,3,5,7,9)
```
셋을 따로 돌린다 — 규칙 54.

## ① 인과 — 미니PC 가 자기 전력을 되찾아야 한다
```
미니PC IDLE 전력 (test_18, 참값 ~12W, 계단으로 확인)
   sp 대조   **0.00 W** (세 시드 모두)     p_raw 0.00, 게이트 0.87~0.99
   목표      **4W 이상**
계단 기여 (t=307.4s / 564.7s): 지금 프로젝터 +9.04 / 충전기 +6.88 을 가져간다
   -> 미니PC 쪽으로 옮겨와야 한다
```
안 움직이면 바닥을 끊는 것으로는 부족하고 **차분 항(C)이 필요**하다는 뜻이다.

## 미리 적어 두는 위험
```
- **`hoAB` 는 차수가 5개만 남는다.** 12.135 가 "h1,h3 만 쓰면 유효차원 4 로
  창당 켜진 기기 수와 맞먹고, 더 낮추면 식별성이 죽는다(규칙 31)" 고 쟀다.
  5개는 그 문턱 바로 위다. **저항 배분(드라이기·포트)이 먼저 무너질 것**으로
  본다 — ③ 이 그 자다.
- 짝수차를 끊으면 **반파 판별(ch50)과는 무관하다** — 그것은 입력 채널이고
  `L_harm` 의 마스크와 별개다. 다만 `res_ohm_half` 의 관문은 `obs_harm` 의
  h2/h4 를 직접 읽으므로 영향 없음을 확인해 둔다.
- h11~h15 를 끊으면 SMPS 3종 구분에 쓰던 정보가 줄 수 있다. 12.166.1 의
  비율 지문에서 SMPS 는 h7 까지 60~73% 로 크므로 h9 까지면 충분할 것으로 본다.
- 바닥이 줄면 `L_harm` 값 자체가 작아져 **다른 항과의 상대 가중이 바뀐다**
  (w_harm 4.0 고정). 마스크 평균으로 나누므로 규모는 유지되지만, 남은 차수의
  성격이 달라지므로 완전히 같지는 않다.
```
