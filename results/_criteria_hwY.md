# 판정 기준 — `gt_plugged` 를 "동작 세션 중" 으로 재정의한다 (12.164)

**결과보다 먼저 적는다 (규칙 22). 시드 3개 중앙으로 판정한다 (규칙 50).**

## 무엇을 바꿨나

```python
# src/synthesis/synthesizer.py  4. 대기 레이어
SESSION_PLUGGED_APPS = ("oven",)
if app not in SESSION_PLUGGED_APPS:
    gt_plugged[app][:] = 1          # 나머지는 그대로 (꽂혀 있으면 1)
```
활성화 배치(5절)가 자기 구간에서 `gt_plugged[oven][t0:t1] = 1` 로 올리므로,
오븐의 `plugged` 는 **세션 중에만 1** 이 된다. `gt_is_on` 과 `gt_standby_p` 는
안 건드렸다 — 그 둘은 이미 맞다. 대기 전류 레이어(6.44mA)도 그대로 둔다.
합성 확인: 다른 8종은 전 구간 1 유지(480건), 오븐만 세션 구간, 전력 분해 성립.

`standby_sig[oven]` 도 같이 FAN_LIGHT(67.4mA)으로 바꾼다 (`--standby-operating
session`, 1·2단계 모두). **짝을 맞추는 것이다** — `idle=σ(plugged)(1−σ(on))` 이
가리키는 상태가 OFF_STANDBY 에서 FAN_LIGHT 으로 옮겨갔으니 고조파 자도 같이
옮겨야 한다. 12.163 은 이 자만 바꾸고 라벨을 안 바꿔서 반증됐다.
핫플은 `gt_plugged` 의 뜻이 안 바뀌었으므로 `session` 이 안 건드린다.

## ① 인과 — 이것이 안 되면 형태가 틀린 것이다

```
(a) standby[oven] (FAN_LIGHT 조용한 창)   9.25W -> **12~16W**
(b) idle[oven] (오븐이 없는 test_5~8)     0.22~0.67 -> **0.2 미만**
```
`(b)` 가 이 처방의 직접 결과다 — 라벨이 "세션 중" 이 됐으니 오븐이 없는 파일에서
`plugged` 가 내려가야 한다. **(a) 와 (b) 가 둘 다 안 움직이면 채택하지 않는다.**
`(b)` 만 되고 `(a)` 가 안 되면 `standby` 머리가 별개 문제라는 뜻이다.
