# 판정 기준 — 반파 채널을 유지하면서 포트↔오븐 축퇴를 깬다 (12.156)

**결과를 보기 전에 적는다 (규칙 22).**

## 자
조인 대조 (규칙 48). `cnn_hwB.pt` 하나에서 적응만 갈라 돌린다 —
구조·파라미터·초기화·자료 순서가 전부 같고 **손실 항만 다르다**.

```
hwB   대조      반파 채널 O, 처방 없음            (이미 있음)
hwC   처방 A    + 동반 부하 항 (팬/조명 14.2W)
hwD   처방 B    + L_res (V^2/R 컨덕턴스 정합)
hwE   둘 다
```
장소A = test_5~8·11~14, 장소B = test_15~18. soft 판정. **--postproc off 로도 잰다**
(12.155.6 에서 후처리가 모델 차이를 가린 전례가 있다 — 포트 −0.565 를 −0.212 로).

## 사는 것 — 이것이 안 되면 실패다
```
① 포트 F1 (장소B, postproc off)   hwB 0.403  ->  hwA 수준 0.969 로 돌아와야 한다
                                   최소 기준: 0.80 이상
② 오븐 유령W (장소B)              hwB 80.4   ->  줄어야 한다. 최소 기준: 60 이하
   (사용자 요청으로 추가. 이번 처방이 직접 겨냥하는 양이라
    이것이 안 움직이면 인과가 틀린 것이다)
```

## 지켜야 하는 것 — 하나라도 무너지면 채택 안 한다
```
③ 드라이기 F1 (장소B)      hwB 0.902  ->  0.87 아래로 내려가면 안 된다
④ 드라이기 강 귀속          hwB ~917W  ->  850W 아래로 내려가면 안 된다 (참값 ~945W)
⑤ 잔차 (장소A / B)         hwB 6.87 / 9.86  ->  나빠지면 안 된다
⑥ 미니PC F1 (장소B)        hwB 0.213  ->  더 나빠지면 안 된다
   (12.155.6 이 안 적었는데 hwA 0.433 -> hwB 0.213 로 이미 −0.220 이다)
⑦ 합성 홀드아웃 MAE         hwB 4.19   ->  나빠지면 안 된다
   12.74 가 짝수차를 되살렸다가 충전기 F1 0.937 -> 0.868 로 무너진 전례
```

## 인과 확인 — 처방이 **의도한 경로로** 들었는가
```
⑧ 처방 A: 오븐 ON 창에서 동반 부하 항이 실제로 발화하는가.
   장소B(오븐 없음)에서 σ(plugged_oven) 이 내려가야 한다.
   내려가지 않고 포트만 돌아오면 **다른 이유로 좋아진 것**이다.
⑨ 처방 B: 잃었던 창(test_16 211 / test_17 186 / test_18 117)에서
   포트가 돌아오는가. 그 창은 V^2/R 이 93/88/93% 로 포트를 지목한 창이다.
```

## 미리 적어 두는 위험
```
- 처방 A 는 오븐이 **있는** 장소 A 에서 오븐 F1 을 낮출 수 있다.
  팬/조명 증거를 요구하는데 복합에서 74mA 는 미니PC 에 묻힐 수 있다.
- 처방 B 는 장소 B 핫플(230~240W, 참조는 460W)과 충돌할 수 있다.
  그래서 L_res 는 포트·오븐에만 걸고 핫플·드라이기는 모델 예측을 그대로 쓴다.
- 둘 다 실패하면 결론은 "반파 채널의 대가는 지금 구조로는 못 없앤다" 이고,
  그때는 채널 유지 여부가 사용자 판단으로 돌아간다.
```
