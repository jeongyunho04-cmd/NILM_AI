# data 디렉터리의 모든 기기별 CSV를 각각 개별 전처리하여 ./output/ 폴더에 개별 저장
python run_preprocessing.py -i "../data/*.csv" -o "./output"
1. 단일 파일 1개만 전처리하는 경우
예를 들어 laptop_charger_tran.csv 파일만 전처리하고 싶은 경우:

cmd


python run_preprocessing.py -i "../data/laptop_charger_tran.csv"
(결과물은 ./output/processed_laptop_charger_tran.csv로 개별 저장됩니다.)

절대 경로를 직접 지정할 수도 있습니다:

cmd


python run_preprocessing.py -i "D:\stm project\NILM_AI\data\laptop_charger_tran.csv"
2. 특정 패턴을 가진 파일들만 골라서 전처리하는 경우 (와일드카드 * 사용)
예를 들어 noise_로 시작하는 파일들만 골라서 전처리하고 싶은 경우:

cmd


python run_preprocessing.py -i "../data/noise_*.csv"
3. 문턱값(ON/OFF 기준 전력)을 직접 지정하여 특정 파일만 전처리하는 경우
cmd


python run_preprocessing.py -i "../data/laptop_charger_tran.csv" --on-power 10.0 --off-power 3.0



방법 1. preprocessing 폴더로 이동 후 실행 (가장 추천 👍)
CMD를 처음 켜셨다면 폴더로 이동한 뒤 실행하는 것이 경로를 길게 치지 않아 가장 간편합니다.

cmd


cd /d "D:\stm project\NILM_AI\preprocessing"
python run_preprocessing.py -i "../data/laptop_charger_tran.csv"
방법 2. 위치 이동 없이 아무 폴더에서나 실행 (전체 경로 입력)
cd 명령어로 폴더를 이동하지 않고 다른 위치(예: C:\Users\... 등)에서 바로 실행하시려면 스크립트 경로와 데이터 경로를 모두 적어주시면 됩니다.

cmd


python "D:\stm project\NILM_AI\preprocessing\run_preprocessing.py" -i "D:\stm project\NILM_AI\data\laptop_charger_tran.csv" -o "D:\stm project\NILM_AI\preprocessing\output"
💡 참고
만약 현재 CMD 위치가 D:\stm project\NILM_AI 라면 이동 없이 아래처럼 짧게 치셔도 됩니다:

cmd


python preprocessing\run_preprocessing.py -i "data\laptop_charger_tran.csv"


1) 원하는 목표 데이터량(Cycle 수)에 맞춰 증강하는 경우
예: laptop_charger_tran.csv 데이터를 **50,000 주기 (약 14분 분량)**로 증강

cmd


python run_preprocessing.py -i "../data/laptop_charger_tran.csv" --target-cycles 50000
실제 실행 결과: 원본 13,440 주기에서 +36,560 주기가 증강되어 exact 50,000 주기의 데이터셋이 완성되었습니다.

2) 기존 데이터량을 N배로 일괄 증강하는 경우
예: 전체 데이터를 2배(2.0x) 크기로 증강

cmd


python run_preprocessing.py -i "../data/*.csv" --augment-factor 2.0
