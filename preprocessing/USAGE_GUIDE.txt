===============================================================================
               NILM AI (1D-UNet) 전체 파이프라인 CMD 실행 가이드
===============================================================================

[프로젝트 개요]
본 가이드는 NILM AI (비침입형 부하 분해) 원데이터 전처리, 12시간 데이터셋 합성, 
어텐션 멀티태스크 1D-UNet 모델 학습 및 분해 평가의 전체 실행 순서를 설명합니다.
다른 컴퓨터로 프로젝트 폴더를 이동시켜도 아래 순서대로 실행하시면 바로 사용 가능합니다.

-------------------------------------------------------------------------------
0. 필수 환경 설치 (새 컴퓨터 설정 시 최초 1회 실행)
-------------------------------------------------------------------------------
1) Python 3.10 이상 설치
2) PyTorch (NVIDIA GPU CUDA 가속 버전) 설치:
   pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu124
3) 필수 수치/그래프 패키지 설치:
   pip install numpy pandas scikit-learn matplotlib tqdm pytest

-------------------------------------------------------------------------------
1. 폴더 구조 준비
-------------------------------------------------------------------------------
작업 디렉토리 예시: D:\NILM_AI\preprocessing
  ├── data\                      <-- 원데이터 Raw CSV 파일 위치 (kettle.csv, fan.csv 등)
  ├── output\                    <-- 전처리 및 합성 데이터셋 생성 폴더
  ├── checkpoint_unet\           <-- AI 모델 학습 결과 저장 폴더
  ├── nilm_preprocessing\        <-- 전처리 핵심 모듈 (synthesizer.py, labeler.py 등)
  ├── run_preprocessing.py       <-- 1단계: 개별 전처리 스크립트
  ├── run_synthesis.py           <-- 2단계: 12시간 데이터셋 합성 스크립트
  ├── train_unet.py              <-- 3단계: 1D-UNet AI 모델 학습 스크립트
  ├── test_unet.py               <-- 4단계: 분해 성능 평가 & 그래프 생성 스크립트
  └── USAGE_GUIDE.txt            <-- 본 가이드 파일

-------------------------------------------------------------------------------
2. CMD 단계별 실행 명령어 (윈도우 CMD 표준 백슬래시 \ 표기)
-------------------------------------------------------------------------------

[Step 0] 작업 폴더 이동 (본인 컴퓨터 경로에 맞게 cd 명령어로 이동 필수)
cd /d "D:\stm project\NILM_AI\preprocessing"

[Step 1] 원데이터 개별 전처리 (data\*.csv -> output\processed_*.csv)
python run_preprocessing.py -i "..\data\*.csv" -o "output"

[Step 2] 12시간 다중 가전 합성 데이터셋 생성 (259만 행, Q/PF/위상 피처 포함)
python run_synthesis.py -i "output" -o "output\synthetic_nilm_12h.csv" -n 2592000

[Step 3] 어텐션 멀티태스크 1D-UNet AI 모델 학습 (GPU 가속, 35 에폭)
python train_unet.py -data "output\파일 이름.csv" -b 256 -e 35

[Step 4] 분해 성능 평가 & 결과 그래프 생성 (MAE/F1 수치 표 및 PNG 그래프 생성)
python test_unet.py -data "output\synthetic_nilm_12h.csv" -ckpt "checkpoint_unet"

-------------------------------------------------------------------------------
3. 엑셀(Excel) 확인용 가벼운 10분 샘플 데이터셋 생성 (선택 사항)
-------------------------------------------------------------------------------
12시간 데이터셋(259만 행)은 엑셀 최대 행수(104만 행)를 초과하여 열리지 않습니다.
엑셀에서 데이터 구조를 바로 확인하고 싶을 경우 10분용 샘플을 생성하세요:

python run_synthesis.py -i "output" -o "output\synthetic_sample_for_excel.csv" -n 36000

-------------------------------------------------------------------------------
4. 주요 출력 결과물 위치
-------------------------------------------------------------------------------
1) checkpoint_unet\best_unet_nilm.pth       : 최종 AI 최적 가중치 모델 파일
2) checkpoint_unet\scaler.pkl                : 데이터 정규화 스케일러 파일
3) checkpoint_unet\disaggregation_result.png    : 분해 파형 비교 시각화 그래프
4) checkpoint_unet\loss_curve.png            : 학습 손실 하강 곡선 그래프
