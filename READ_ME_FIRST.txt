이 폴더의 구조는 저장소 루트와 같다. **폴더 안의 내용물을 저장소 루트에
덮어쓰면 된다.** (_to_training_pc 폴더 자체가 아니라 그 안의 것들)

    NILM_AI/
      +- src/                <- run_live.py 덮어쓰기, run_score_live.py 신규
      +- tests/              <- test_live_ring.py 신규
      +- processed_data/     <- real_events.json 덮어쓰기, test_5_timeline.json 신규
      +- data/               <- test_5/6/7.csv 신규
      +- MODEL_TRAINING_DESIGN.md            덮어쓰기
      +- TEST_DATASET_TIMELINE_ANALYSIS.txt  덮어쓰기
      +- HANDOFF_2026-08-23.md               신규

--------------------------------------------------------------------------------
  덮어쓰기 전에
--------------------------------------------------------------------------------

  real_events.json 은 학습 PC 쪽 것을 먼저 백업할 것.
  이 파일이 이번 작업의 핵심 산출물이다 (test_5/6/7 병합 + test.2/test3 정정).

      copy processed_data\real_events.json processed_data\real_events.json.before

  MODEL_TRAINING_DESIGN.md 와 TEST_DATASET_TIMELINE_ANALYSIS.txt 는
  **덧붙이기만 했다.** 학습 PC 에서 그 사이에 고친 것이 없다면 그냥 덮어써도 된다.
  고친 것이 있으면 12.30 절 이후 / [6-1] 절 이후만 잘라 붙일 것.

--------------------------------------------------------------------------------
  덮어쓴 뒤 확인
--------------------------------------------------------------------------------

  1) 회귀 테스트 (데이터 불필요, 15개)

       python -m pytest tests/test_live_ring.py -q

  2) 정답 파일이 제대로 읽히는지

       python -c "from src.evaluation.real_events import load_events; E=load_events(); print(list(E)); print({k: v.get('_label_provenance') for k,v in E.items()})"

     기대: ['test.2','test3','test_4','test_5','test_6','test_7']
           test_5/6/7 이 human_switching_log

  3) 전처리 다시 (test_5/6/7 이 composite_eval 로 들어가야 한다)

       python -m src.run_preprocess_and_label

--------------------------------------------------------------------------------
  넣지 않은 것 — 일부러
--------------------------------------------------------------------------------

  real_events.json.bak ~ .bak6   정정 이력은 파일 안 _verification 필드에 있다
  results/*.jsonl                재생 로그. 재생성된다
  processed_data/npz/            시연 노트북에서 만든 것. 학습 PC 것이 정본이다

  data/beam_projector.csv, oven.csv
      시연 노트북에서만 이름이 beam_projector_1 / oven_1 로 돼 있어 되돌렸다.
      학습 PC 는 원래 올바른 이름이므로 건드릴 것 없다.

--------------------------------------------------------------------------------
  무엇부터 할 것인가
--------------------------------------------------------------------------------

  HANDOFF_2026-08-23.md 의 5절 목록을 볼 것. 요약하면:

    B-5 (재학습 불필요, 먼저)  test_5/6/7 로 재채점해 기준선을 간다.
                              지금까지의 실측 수치는 전부 AI 추정 라벨 기준이다.
    B-1                       적응에서 SMPS 게이트 얼리기 (--ckpt-smps 정식화)
    B-2                       미니PC 작업 상태 비율 올리기 (지금 11.5%)
    B-3                       충전기 충전 궤적을 세그먼트 풀에
    B-4                       데이터 양 스윕 (12.28.4 가 지목한 미실시 진단)

  각 항목에 판정 기준을 미리 적어 두었다. 돌리기 전에 읽을 것.

--------------------------------------------------------------------------------
  실시간 추론을 돌릴 때 (시연 노트북에서든 학습 PC 에서든)
--------------------------------------------------------------------------------

      python -m src.run_live --csv data/live.csv ^
          --ckpt results/adapt_v17.pt --ckpt-smps results/cnn_v17.pt

  --ckpt-smps 를 빼면 충전기를 -60% 로 읽는다 (붙이면 -18%).
