## 1. 지금 어디까지 왔나

목표는 SMPS 3종(노트북 충전기 65W, 미니PC 어댑터 65W, 빔프로젝터)을 60Hz 고조파
h1~h15 로 분리하는 것. 회로 모델을 세워 합성 데이터를 만들고, 그 모델로 추론까지 한다.

```
[완료]  회로 모델 3종        파형 재현 6~8% (계측 RC 적용 후)
[완료]  원시 파형 피팅 파이프라인  Cx 직접측정 → Z변환 초기값 → 시간영역 정밀화 (4~20초)
[완료]  결합 생성기          fcm.forward(), 시뮬레이터 고정점
[완료]  Cramér-Rao 하한      분석-합성 추정기가 바운드에 도달 (미니PC 0.16W/0.5초)
[완료]  혼합 실측 검증        6개 혼합, 전력 오차 0.4~2.5W
[완료]  전압 텍스처 라이브러리   vtexture_lib.py
[대기]  200W 저항 부하 측정    전압 채널 교정 (§4)
```

**모델 정밀도는 여기서 멈춘다.** 6~8%는 실기기에 대한 문헌 수준이다
(Mesas 2011 실제 PC·TV 5~10%, Xie 2024 <5%, 단 정격 1점). 구조 요소 다섯을
시험해 넷이 기각됐다(§3). 더 내리려면 실험실 계측이 필요하고 이 프로젝트 밖이다.

## 2. 반드시 알아야 할 관례 — 여기서 두 번 틀렸다

**위상 관례**
```
모든 스펙트럼은  X(h) = |X_h| · exp( j·( arg X_h − h·arg V_1 ) )     ← "h배" 관례
절대 위상 스펙트럼에 되돌릴 때는  exp( +j·h·φ₁ ).   exp(+j·φ₁) 만 곱하면 틀린다.
  (vtemplate 검증에서 이 실수로 6.3% 가 8.6% 로 나빴다)
```

**전압 파형 재구성**
```
v(t) = Σ √2·|V_h|·cos(2πfht + φ_h)      ← cos 기준. sin 으로 하면 부호가 뒤집힌다.
짝수 차수는 계측 아티팩트이므로 제외. 반파 대칭화 (v(t) − v(t+T/2))/2 가 정확한 보정.
  (2차 다항식 보정 vcorr.json 은 폐기 — 전압 피크를 21V 깎아 모델을 망가뜨렸다)
```

**시뮬 전류에 계측 RC**
```
i_meas 와 비교할 때는 rc(i_sim) 으로.  1극 저역통과 fc = 1591.55 Hz (1kΩ·100nF).
이걸 안 걸면 RC 지연이 L 로 흡수된다 (L 988µH → 750µH).  전 구간 30% 개선.
```

**세션 정렬 자가진단**
```
2Hz 세션마다 V–I 정렬이 다를 수 있다. 저항 부하의 ihdeg1 이 ±2° 밖이면 그 세션은 오염.
알려진 오염: laptop_charger_5C.csv (+7샘플), minipc_4C.csv (+1~2샘플).
```

## 3. 기각된 가설 — 다시 시도하지 말 것

| 가설 | 검정 | 결과 |
|---|---|---|
| 채널 시간지연 τ = −17°/h | 저항 부하 10 이벤트 | 0.63°±1.26° → 기각 |
| Z변환 선형 추정으로 최종 파라미터 | 실물 3종 | 파형 12~49% → 초기값으로만 사용 |
| Shockley 다이오드 (nVt) | rd 제거 후 재피팅 | nVt 하한 고착 → 다이오드 아님 |
| NTC 서미스터 | R(P) 동작점별 | 47~73W 평평, 19W 낮음 (반대) → 기각 |
| 충전기 19W 버스트 모드 | 주기별 통계 | I1 CV 0.037 단봉 → 기각 |
| π형 EMI 필터 | Cx 분배 자유 | 중간 0.5%p, 양끝 무변화 → 미미 |
| 전압 h17+ 함수형 사전분포 | 지수/평탄화/Lanczos | 전부 실패 → 경험적 템플릿만 |
| 포트로 전압 채널 교정 | 교정 적용 후 재피팅 | 8.4% → 15.7% 악화 → §4 |

## 4. 다음에 할 것 (측정 필요)

**① 200W 저항 부하 원시 스냅샷 (최우선)**
백열등 200W 또는 소형 히터. RMS 0.9A, 피크 1.3A 로 **LOW 레인지 안**에 들어와야 한다.
포트(6.3A)는 HIGH 레인지라 고전류 아티팩트 7% 가 섞여 교정기로 못 쓴다.
용도: 전압 채널 차수별 이득·위상 교정, 장소별 진짜 vh3, h17+ 계통성 확인.

**② 이벤트 순간 스냅샷 (펌웨어 한 줄)**
전력 계단 감지 시 직전 5주기 + 직후 20주기 캡처. 인러시 dI/dt 가 10,000~20,000 A/s 라
L_line 이 2~4V 강하로 드러난다(정상상태로는 SNR ~1 이라 불가). 덤으로 인러시 서명은
새 판별 축이다 (NTC 유무, C_dc 크기).

**③ 세션 텍스처 갱신용 스냅샷 (요청 A′)**
10~15분마다 원시 20주기(≈2초). 텍스처는 장소가 아니라 **세션**에 고정된다.

**④ 미니PC 절전 모드 단독 스냅샷**
7W 잔차가 덧셈 성분. 대기 전원 서명을 측정해서 `I = I_main(P−P_sb) + I_sb` 로.

## 5. 확정된 사실 모음

**계측계**
- 전압 채널 h2 = 2.58% 는 100% 아티팩트 (포트 전류 h2 = 0.04%, 계통은 완벽 대칭)
- HIGH−LOW 전류 채널 지연 1.2샘플(80µs), 4개 파일에서 일정 → 스티칭 오차 원인
- HIGH 레인지 6.3A 에서 V/R 대비 7% 왜곡 (2샘플 앞섬 + 편측 혹)
- 전압 h17~h31 (0.23%) 은 계통 실재 (포트 전류 0.22%, 비 0.94)

**물리**
- 선로 R = 0.48~0.52Ω (장소 C), L 은 미측정 → 0~400µH 랜덤화
- L_line 불확실성이 서명에 주는 영향 ≤7° (세션 텍스처 7~10°, 장소 간 12~27° 보다 작다)
- 결합(Z·I)은 조합 전압 차이의 1/12. **지배 축은 세션 텍스처**
- 실제 SMPS 의 실효 직렬 R 은 4~7Ω (Mesas 실기기 PC 5.96 / TV 4.1Ω 과 같은 범위)

**추정 한계 (CRB, 계측 잡음 기준)**
```
창          충전기   미니PC  프로젝터
0.5초       0.26W   0.16W   0.13W
10초        0.06W   0.04W   0.03W
```
분석-합성 추정기가 이 바운드에 도달했다(비 0.7~1.1). 판별 정보의 76% 가 h3~h9 에 있고
h13 은 6% — h13~h15 정밀도에 매달릴 이유가 없다.

**추론 구조 (test_19 에서 검증)**
```
1. 큰 이벤트(|ΔP|>25W)로 프로젝터·충전기 on/off 고정
2. 알려진 기준 구간(상태 확실)을 잡고
3. 그 델타로 작은 기기(미니PC)를 푼다        ← 공통 모드 모델 오차가 상쇄된다
절대 분해는 실패한다 (충전기 54W ≡ 프로젝터 49.5 + 미니PC 5.5, 상관 −0.88)
미니PC ON 하한은 5W. 유휴 5W 와 OFF 는 90W 아래서 경계선 → 전이(14W→0)로 판정
```
